code block ها و admonition ها
code block ها نگه داشته می‌شوند (<pre>): مخاطب این جست‌وجوگربرنامه‌نویس Django است و اکثر پرسش‌های فنی بدون مثال کد پاسخ کاملندارند. برچسب‌های headerlink و شماره‌ی خطوط حذف شده‌اند تا کد تمیز بماند.
باکس‌های admonition (note/warning/versionadded) حذف نمی‌شوند و بابرچسب نوعشان در متن علامت‌گذاری می‌شوند (مثل [warning] ...): اینباکس‌ها اغلب هشدارهای امنیتی یا اطلاعات سازگاری نسخه‌ها را دارند که در پاسخ به پرسش‌های فنی ارزشمند است. در نسخه‌ی اولیه حذفشان کردم،اما با مرور صفحات به این نتیجه رسیدم که اطلاعات مفیدی از دست می‌رود.
